# 온라인 업무 수첩

업무·개인 일정을 등록하고 주간·월간 현황을 확인하는 개인 일정 관리 서비스입니다. 현재 `edu-apply-02` 프로젝트의 메인 서비스이며, 실행 파일과 관련 자료는 모두 프로젝트 루트에 있습니다.

HTML·CSS·순수 JavaScript로 구성한 로컬 실행용 프로토타입입니다. 로그인이나 외부 서버 없이 현재 브라우저에 일정을 저장합니다.

웹서버·온라인 데이터베이스 전환 계획은 [웹서비스 전환 검토서](WEB_SERVICE_PLAN.md)에 정리했습니다. 권장 구조, DB·API 설계, 로그인·권한, 데이터 이전, 운영 비용과 결정 사항을 다룹니다. 해당 계획은 미구현이며 아래 설명은 현재 실행되는 로컬 버전 기준입니다.

## 실행

프로젝트 루트의 [index.html](index.html)을 Chrome 또는 Edge에서 더블클릭해 여세요. 설치, 빌드, 외부 라이브러리, 서버 없이 실행됩니다.

1. 일정 등록에서 업무 또는 개인 분류, 날짜, 시작·종료 시간, 내용을 입력합니다.
2. 등록하면 해당 날짜가 있는 기간으로 이동합니다.
3. 주간·월간 보기와 이전·이번·다음 기간 버튼으로 일정을 확인합니다.
4. 일정 카드 또는 목록의 변경 버튼으로 수정하고, 취소 버튼으로 삭제합니다. 삭제 전 확인 창이 표시됩니다.

1번 일정 현황 위의 **7일 이내 처리할 일정**에서 오늘부터 7일 후까지의 업무·개인 일정을 확인할 수 있습니다. 오늘은 `D-day`, 이후는 `D-1`~`D-7`로 표시하며 날짜·시작 시간 순으로 정렬합니다. 아래에서 선택한 주·월이나 분류와 관계없이 전체 저장 일정을 기준으로 표시합니다. 상단 카드에서도 일정 변경·취소가 가능합니다.

3번 등록 내용 목록에는 D-day 열이 있으며, 지난 날짜는 `D+1`처럼 표시합니다. 계산 기준은 접속한 기기의 현재 날짜이고, 기존 일정 날짜를 처리일로 사용합니다. 별도 마감일·완료 상태를 추가하는 기능은 아닙니다.

일정은 07:00~23:00 사이에 30분 단위로 등록합니다. 마지막 시작 시간은 22:30이며, 시작 시간을 바꾸면 종료 시간이 30분 뒤로 설정됩니다. 업무·개인 분류와 관계없이 같은 날 시간이 겹치는 일정은 등록할 수 없습니다. 앞 일정의 종료 시각에 다음 일정을 시작하는 것은 가능합니다.

## 저장 및 사용 범위

- 일정은 현재 브라우저의 localStorage에 저장됩니다. 키는 `online-work-notebook.standalone.v1`입니다.
- 해당 실행 위치에 저장된 데이터가 없으면 빈 일정으로 시작합니다. 예제 일정이나 다른 서비스의 데이터를 자동으로 가져오지 않습니다.
- 같은 저장 영역을 사용하는 다른 탭에서 일정을 변경하면 저장 이벤트로 반영합니다. 로컬 파일로 실행할 때 저장 영역과 탭 간 반영 여부는 브라우저 동작에 따라 달라질 수 있습니다.
- 파일 위치나 브라우저가 바뀌면 기존 일정이 표시되지 않을 수 있습니다. 브라우저 데이터를 삭제하면 일정도 삭제됩니다.
- 손상된 저장 데이터를 발견하면 덮어쓰지 않고 변경을 중단합니다. 저장 실패 시 입력 내용은 유지됩니다.
- 로그인, 서버 저장, 여러 기기 간 공유, 알림은 포함되지 않습니다. 현재 결과물은 로컬 실행용 프로토타입입니다. 온라인 공동 사용에는 별도의 서버·인증·데이터베이스 구성이 필요합니다.

### 메인 폴더로 이동한 뒤 기존 일정이 보이지 않는 경우

저장 키는 이전 하위 폴더 버전과 동일하지만, localStorage 데이터는 프로젝트 파일에 포함되지 않습니다. 브라우저가 파일 경로별로 저장 영역을 구분하면 실행 위치가 바뀐 후 빈 일정으로 보일 수 있습니다. 자동 이전·백업·가져오기 기능은 현재 없습니다. 이전 실행 위치에 저장된 일정이 있다면 해당 위치와 브라우저에서 먼저 확인하세요.

## 확인

[test.html](test.html)을 열면 업무 규칙 테스트 25개의 PASS/FAIL을 볼 수 있습니다.

Node.js가 있다면 프로젝트 루트(`C:\work\edu-apply-02`)에서 실행합니다. 패키지 설치는 필요하지 않습니다.

```powershell
node smoke-test.cjs
```

이 명령은 업무 규칙과 모의 화면 환경에서의 등록·중복 거부·변경·월간 보기·분류 필터·저장 복원·취소·저장 오류 처리를 점검합니다. 실제 브라우저의 배치나 조작을 검증하는 테스트는 아닙니다.

실제 브라우저에서는 다음을 확인하세요.

1. 일정을 등록하고 새로고침한 뒤에도 표시되는지 확인합니다.
2. 주간·월간 전환, 기간 이동, 업무·개인 필터를 확인합니다.
3. 겹치는 시간은 거부되고, 앞 일정 종료 시각에 시작하는 일정은 등록되는지 확인합니다.
4. 변경 저장·변경 취소와 일정 삭제 확인 창의 돌아가기·일정 취소를 확인합니다.
5. 좁은 화면에서 폼을 조작하고 일정표를 가로로 스크롤할 수 있는지 확인합니다.
6. 오늘·7일 후 일정은 상단에 표시되고, 지난 날짜·8일 후 일정은 제외되는지 확인합니다. 기간·분류를 바꿔도 상단 목록이 유지되고 변경·취소가 반영되는지 확인합니다.
